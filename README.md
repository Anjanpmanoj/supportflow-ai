# SupportFlow AI

**SupportFlow AI** is an AI-assisted customer support platform that helps users raise support tickets and enables support staff to manage issues with AI-generated reply suggestions and human review.

## Live Demo

[Open SupportFlow AI](https://supportflow-ui.onrender.com)

## How to Use

1. Open the live application and log in or register for an account.
2. Create a support ticket by describing your issue and selecting the appropriate category.
3. The system processes the ticket and generates an AI-assisted reply based on the available support policies.
4. Support staff can review the suggested response, make changes if needed, and respond to the customer.
5. Tickets requiring additional attention can be escalated for human review.

**Note:** AI-generated responses are suggestions and may require human review before a final response is sent. Response times depend on support staff availability.

## Technology Stack

- FastAPI
- Streamlit
- SQLite
- LangChain and LangGraph
